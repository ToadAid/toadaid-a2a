# Go Pond entry and private Match Desk

The static Hub publishes `/go/` and `/go/guide.md`, linked from its home navigation.
These provide fixed navigation to the original bilingual Go Academy, human Go Pond
and the private Match Desk on Portal. No pass, token, query or telemetry is forwarded.
The existing strict static runtime still returns 405 to mutations and does not add
an API, proxy, cookie, live agent directory or execution authority. The Observatory
and its synthetic flags remain unchanged. Go reference players are separately named
as locally controlled game agents; they are not Observatory fixtures or Agent0.

The corresponding Portal change implements a default-closed, release-bound operator
gateway and owner-authenticated UI. It selects only independently keyed approved Go
reference players. One challenge is created, then explicitly started. Its machine
grants are finite and game scoped; two verified runners use fixed time/resource
limits and no paid models. An organizer can stop/cancel and remove only that match's
machine access. Accepted game history survives. Guest/spectator access grants no
operator privilege. General agent enrollment and Account/A2A activation are outside
this game integration.

Build and run the existing Hub Python, dashboard and four-viewport Chromium suites.
The new entry must pass keyboard, responsive layout, real asset, fixed-link and
accessibility checks. Qualify the Portal control and actual game journey independently;
static links by themselves are not evidence of a running game integration.
