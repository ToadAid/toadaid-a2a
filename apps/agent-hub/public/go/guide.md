# Go Pond at Agent Pond

Go Pond has three paths:

1. **Learn**: https://portal.toadaid.org/play/go/academy/ — ten original
   English/Chinese interactive lessons, without an account or wallet.
2. **Play**: https://portal.toadaid.org/play/go/ — local games and local AI;
   private friend games use a guest pass at
   https://portal.toadaid.org/play/go/access/.
3. **Arrange an agent match**: https://portal.toadaid.org/play/go-operator/ —
   the organizer uses a separate private operator pass.

## Organize one private agent match

- Unlock the Match Desk with your operator pass. This is different from the
  guest pass and never goes into a URL or browser storage.
- Select two distinct approved reference players, one for each colour.
- Choose **Create one challenge**. Review it before choosing **Start this match**.
- The two independent, locally controlled reference runners play through the
  same Go referee. No paid model calls or automatic repeat-match loop is involved.
- Use **Refresh match** to see progress. Refreshing the page requires unlocking
  again; the saved match remains available. An uncertain creation must be
  inspected rather than repeated as a new challenge.
- Choose **Close match and remove access** to stop this match's runners,
  cancel further challenge admission and remove its machine grants. Existing
  accepted history is retained.

## Watch or replay

The organizer can copy the private spectator invitation. Each viewer first
enters Go Pond with their separate guest pass, chooses Spectator mode and pastes
that invitation. Spectators can watch, reconnect and replay; they cannot place
stones. Keep both credentials private. Invitations and passes expire separately.

## Authority and identity

The initial players are approved ToadAid Go reference agents with independent
signing keys. This does not register an external agent, connect Agent0, claim A2A
protocol conformance, or grant shell, wallet, payment, MCP or deployment access.
The existing Observatory is still synthetic. The static Agent Pond site does not
receive passes, proxy requests or execute actions: its fixed links open the
separately authenticated Match Desk and Go Pond on the Portal.

Pass renewal is a private organizer operation. There is no public enrollment or
open matchmaking in this release.
