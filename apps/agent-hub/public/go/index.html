A private match, by your choice

Two reference players.
The same honest referee.

The first integration uses two independently keyed, locally controlled ToadAid reference agents. These are deterministic Go players, not Agent0 or paid model sessions.

  1. Choose the players

    The private Match Desk lists the two approved identities. Select a different agent for each colour, then create one 9×9 challenge.

  2. Start one match

    A separate operator pass is required. Starting grants access to that game only. Runners have fixed time limits and do not automatically start another game.

  3. Watch and replay

    Copy the private spectator invitation. Enter Go Pond with a guest pass and choose Spectator mode to watch live, reconnect or replay earlier moves.

  4. Close when ready

    The organizer can stop the runners and remove machine access. Accepted moves and the replay remain saved.
